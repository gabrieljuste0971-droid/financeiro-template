        Dados
        
Onde ficam os seus dados

        
Por padrão, no próprio navegador do seu computador. Nada sobe para servidor nenhum.

      

      

        
No navegador (padrão)
Funciona na hora, sem conta. Os dados ficam só naquele navegador: limpar o histórico apaga tudo, e outro computador não vê. Bom pra começar e pra quem usa sozinho.

        
Na nuvem (Supabase)
Conta gratuita, dados em banco de verdade, com login. Acessa de qualquer lugar. O template já traz o banco pronto; o Claude te guia.

          
Cole quando quiser migrar
Quero guardar os dados do Financeiro no Supabase em vez do navegador. Me guie passo a passo: criar o projeto gratuito no supabase.com, rodar o arquivo supabase/schema.sql no SQL Editor, preencher o .env com a URL e a chave pública, e testar o login. Me avise do que eu preciso fazer no site do Supabase e do que você faz aqui.

        

      

    

  


  

    

      

        Socorro
        
Deu errado?

        
Os tropeços mais comuns e o que colar no Claude.

      

      

        
O Claude diz que não encontrou "npm" ou "node"
O Node.js não está instalado ou o Claude Code foi aberto antes da instalação. Instale pelo nodejs.org, feche e abra o Claude Code de novo e repita o pedido.

        
Ele pede permissão toda hora
É normal: o Claude Code pede antes de rodar comandos e mexer em arquivos. Aceite os pedidos de npm install, npm run dev e de criar ou editar arquivos dentro da pasta do projeto. Se ele quiser mexer fora da pasta, recuse e pergunte por quê.

        
Abri o endereço e a tela está em branco
Cole no Claude: "A tela em localhost está em branco. Abra o console do navegador, leia o erro e corrija." Nove em dez vezes é um arquivo faltando que ele resolve sozinho.

        
Diz que a porta 5173 está em uso
Outro projeto está rodando. Cole: "Rode em outra porta livre e me diga o endereço."

        
Fechei tudo. Como abro de novo?
Abra a mesma pasta no Claude Code e cole: "Rode o projeto e me mostre o endereço." Os seus dados continuam lá, no navegador.

        
Só tenho o chat do Claude, não o Claude Code
O chat não instala nem roda programas. Baixe o app do Claude para computador e use a aba Code, ou instale pelo terminal como no passo 1. Enquanto isso, dá pra abrir a demonstração online que o seu professor te passou.

        
Quero tirar os dados de exemplo
Na faixa do topo da tela, clique em Começar do zero. Se a faixa já sumiu, cole no Claude: "Apague os dados de exemplo do Financeiro e deixe a tela vazia."
